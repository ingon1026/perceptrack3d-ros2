  Using an augmented matrix and an augmented vector, it is possible to represent
  both the translation and the linear map using a single matrix multiplication.
  The technique requires that all vectors be augmented with a "1" at the end,
  and all matrices be augmented with an extra row of zeros at the bottom,
  an extra column — the translation vector — to the right, and a "1" in the
  lower right corner. If A is a matrix,

      [ y ]   [ A       b ] [ x ]
      [ 1 ] = [ 0 ... 0 1 ] [ 1 ]

  is equivalent to the following   y = A x + b.
  The above-mentioned augmented matrix is called an affine transformation matrix.
